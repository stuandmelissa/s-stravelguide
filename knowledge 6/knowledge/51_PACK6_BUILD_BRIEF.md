# Pack 6 Build Brief

## Goal
Make the trip spatially usable without turning S&S into a fragile replacement for a mature navigation app.

## Required implementation
- render GeoJSON waypoints and daily connections
- filter pins by day, priority, and type
- launch Apple Maps or Google Maps
- import/export GPX and KML
- cache map metadata for offline access
- display coordinate confidence
- support completion and skip state

## Definition of done
A traveler can open any trip day, understand the geographic sequence, identify the highest-value stops, launch the next destination, and retain the route context without cellular service.

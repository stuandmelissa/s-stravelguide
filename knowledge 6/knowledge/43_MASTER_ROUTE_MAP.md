# Master Route Map

The overview follows the working itinerary:

Marion → Fort Collins → Rocky Mountain National Park → Moab/Arches → Bryce Canyon → Zion/Springdale → Idaho Falls → Grand Teton/Jackson → Yellowstone → Beartooth Highway → Billings → Devils Tower → Deadwood → Marion.

The overview map should emphasize sequence and progress, not exact road geometry. Each day card launches a dedicated route link with only that day's stops to avoid waypoint-limit failures in consumer map apps.

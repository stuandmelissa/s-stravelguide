# Reservations and Passes

## Core Pass
America the Beautiful annual pass is the default federal recreation pass for this trip.

## Reservation Categories
Track each item as one of:
- Confirmed
- Planned
- Not required
- Verify before arrival
- Cancelled

## Items to Track
- Hotels
- RMNP access requirements
- Arches access requirements
- Jackson rafting
- Jackson aerial tram
- Any shuttle or parking reservation
- Park alerts and road closures

## Data Integrity
- Store confirmation numbers only when supplied by Stuart.
- Show the source and last verified date for changing requirements.
- Never represent an unverified plan as a confirmed booking.

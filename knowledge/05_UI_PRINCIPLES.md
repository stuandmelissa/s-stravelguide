# UI Principles

## Design Goal
Feel like Apple Weather + Flighty, not TripAdvisor.

## Core Rules
- One primary action per screen.
- Large touch targets.
- One-handed operation.
- Generous whitespace.
- Large photography.
- Calm, premium appearance.
- Avoid clutter.

## Primary Screens
Home
Today
Map
Hotels
Memories

The Home screen should be the default landing page every morning.

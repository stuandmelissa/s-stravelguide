# S&S Travel Guide — Knowledge Base

This folder is the product specification. Read every file in numeric order before generating or modifying code. These documents are the source of truth for all development.

## Index

| Files | Layer | Contents |
|---|---|---|
| 00–04 | Foundation | Mission, travelers, travel philosophy, product principles, constitution |
| 05–12 | UI & UX | UI principles, design system, components, UX writing, color, motion, accessibility, offline strategy |
| 13–21 | Trip Brain | Master itinerary, daily rhythm, trip rules, hero moments, weather, wildlife, photography, driving, cheat sheets |
| 22–31 | Road Operations | Hotels, food, packing, safety, connectivity, navigation, reservations, emergency, data model, build brief |
| 32–41 | Park Intelligence | Scoring model, per-park playbooks (RMNP, Arches, Bryce, Zion, Grand Teton, Yellowstone, Devils Tower), decision engine, build brief |
| 42–51 | Maps & Routes | Spatial architecture, route maps, scenic layers, offline maps, link rules, layer spec, confidence model, QA checklist, build brief |

## Related directories

- `data/` — machine-readable seed data (trip operations, park intelligence, sources, waypoints, map manifest)
- `public/maps/` — GPX, KML, and GeoJSON route assets plus navigation launch links

# Daily Route Files

Each daily GPX contains ordered waypoints plus a simple route element. Recommended behavior:

1. Show the ordered stops inside S&S.
2. Let the traveler mark stops as completed or skipped.
3. Rebuild the launch link using only remaining stops.
4. Cap third-party navigation launches at 8 intermediate waypoints.
5. Preserve the overnight destination even when optional stops are removed.

The files are planning aids. Live closures, weather, construction, and park instructions always take precedence.

# Travel Philosophy

Rule 1: Never rush an amazing experience.

Rule 2: Visit parks before driving whenever practical.

Rule 3: Build buffer into every day.

Rule 4: Wildlife overrides schedules.

Rule 5: If ahead of schedule, recommend slowing down instead of adding attractions.

Rule 6: Local restaurants beat chains when both fit the day.

Rule 7: Hotels are part of the vacation, not just places to sleep.

# Map Layer Specification

## Default layers
1. Route overview
2. Overnight anchors
3. Hero stops
4. Current-day stops

## Optional layers
- easy hikes
- wildlife zones
- photo stops
- fuel and food
- restrooms and visitor centers
- emergency resources

## Pin hierarchy
Hero stops use the strongest visual weight. Core stops are secondary. Bonus stops remain subdued until selected. Completed stops become checked but stay visible. Skipped stops are hidden from the active route while remaining in trip history.

## Detail sheet
Tapping a pin shows title, type, priority, expected time, parking note, crowd note, confidence, offline availability, and navigation buttons.

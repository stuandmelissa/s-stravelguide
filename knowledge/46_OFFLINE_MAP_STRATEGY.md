# Offline Map Strategy

Before departure, download offline regions in the navigation app for northern Colorado, eastern Utah, southwest Utah, southeast Idaho, northwest Wyoming, south-central Montana, northeast Wyoming, western South Dakota, and the route home.

Inside S&S, cache:
- waypoint metadata
- map thumbnails or lightweight vector tiles where licensing permits
- GPX/KML/GeoJSON assets
- daily cheat sheets
- emergency numbers and visitor-center information

The app should display a visible offline badge and the timestamp of the last successful data refresh. Never imply that an offline base map contains current closures.

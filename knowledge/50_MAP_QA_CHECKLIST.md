# Map QA Checklist

- All JSON parses successfully.
- Every waypoint ID is unique.
- Every daily stop references an existing waypoint.
- Latitude is between -90 and 90; longitude between -180 and 180.
- Each GPX and KML file opens in a standard viewer.
- Approximate locations are labeled.
- Daily route order matches the itinerary.
- Overnight destinations are never optional.
- External links use HTTPS.
- The interface distinguishes overview lines from turn-by-turn navigation.
- Offline mode never claims current road status.
